# Test task

Цель - проверить, что реализованная задача работает правильно с точки зрения пользователя

## Порядок работы

1. Изучи требования задачи и изменения текущей ветки, чтобы понять, какой функционал нужно проверить
2. Если в задаче есть DoD (Definition of Done), обязательно проверь каждый его пункт
3. Составь дополнительные сценарии тестирования, включая негативные случаи и граничные значения
4. Проверь функционал в браузере. Можешь использовать установленный `playwright-cli`
5. Проверяй не только успешное выполнение сценариев, но и валидацию, ошибки, сохранение данных и влияние изменений на связанный функционал
6. При обнаружении ошибки перепроверь её и выясни причину, используя код, консоль браузера и сетевые запросы
7. Если существуют подходящие автоматические тесты, используй их для дополнительной проверки
8. Не считай сценарий пройденным без фактической проверки

## Формат результата

- **DoD** - статус проверки каждого пункта, если он есть в задаче
- **Ошибки** - найденные проблемы, шаги воспроизведения и ожидаемое поведение
- **Дополнения к DoD** - дополнительные проверки, которые потребовались или выявили ошибки и которые стоит добавить в DoD
- **Не проверено** - сценарии, которые не удалось проверить, и причины

Не добавляй пустые разделы

## Ограничения

- Не изменяй исходный код, не создавай коммиты и не делай push
- Не выполняй опасные действия и не изменяй реальные пользовательские данные
- Для тестирования используй тестовые данные
- Не заявляй об успешном тестировании, если браузер или приложение недоступны
