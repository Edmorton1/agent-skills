# Test task to fix

Цель - исправить ошибки, из-за которых задача вернулась в To Fix после тестирования

## SpaceHub

1. Определи ID текущей задачи из контекста, названия ветки или переданного пользователем ID
2. Получи задачу через MCP `sph_issues`
3. Если не удалось однозначно определить задачу, запроси её ID у пользователя
4. Изучи описание задачи, DoD и раздел **«Результаты тестирования»**

## Порядок работы

1. Изучи все замечания в разделе «Результаты тестирования»
2. Для каждой ошибки найди причину в коде. При необходимости воспроизведи проблему через установленный `playwright-cli`
3. Исправляй подтверждённые ошибки, не нарушая требования задачи и существующий функционал
4. Если замечание спорное, непонятное или противоречит требованиям, не исправляй его без согласования. Опиши мне проблему
5. После исправлений повторно проверь сценарии, на которых задача упала, и связанные пункты DoD
6. Запусти подходящие тесты и проверки проекта
7. Не изменяй код, не относящийся к исправлениям

## Формат результата

- **Исправлено** - какие ошибки устранены и что изменено
- **Проверки** - какие сценарии и тесты выполнены, результаты
- **Нужно решение** - спорные или непонятные замечания
- **Не исправлено** - оставшиеся проблемы и причины

Не добавляй пустые разделы

## Ограничения

- Не делай commit и push
- Не изменяй статус задачи и результаты тестирования в SpaceHub
- Не считай ошибку исправленной без проверки
- Не перезаписывай существующие изменения пользователя
- Используй только тестовые данные, не выполняй опасные действия с реальными данными
