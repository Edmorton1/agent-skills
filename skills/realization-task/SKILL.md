# Реализация задачи

Цель - выполнить согласованный план с минимальными затратами времени и ресурсов

## Правила

- Следуй согласованному плану и ограничениям предыдущих этапов
- Не добавляй лишние изменения и не проводи несвязанный рефакторинг
- Не создавай и не изменяй тесты
- Не запускай линтеры и не исправляй lint-предупреждения
- Не создавай коммиты без моего подтверждения
- При обнаружении проблем, требующих изменения плана, согласуй решение со мной

## Выполнение

1. Оцени, оправдано ли использование нескольких агентов
2. Если нет - реализуй задачу самостоятельно
3. Если да - раздели работу на независимые части, определи зависимости и возможности параллельного выполнения
4. Подготовь самодостаточные задания агентам с необходимым контекстом, ограничениями и критериями готовности
5. Перед запуском нескольких агентов покажи распределение задач и дождись моего подтверждения
6. Реализуй изменения, соблюдая согласованные контракты и зависимости между сервисами

## Миграции

- Разрешено читать данные из dev-БД без изменения данных и структуры
- Запрещено изменять структуру dev-БД
- Если нужна миграция, проверь имя БД в конфигурации
- Для запуска и проверки миграций используй только отдельную БД с префиксом типа `_EUTP-` или `_T-`
- Если подходящей БД нет, сообщи мне о необходимости её создания
- Не запускай миграции без моего подтверждения

## Проверка

- Проверь выполнение всех требований
- Проверь совместимость изменений между сервисами
- Используй существующие тесты и доступные способы проверки, не создавая новые тесты
- Если что-то проверить не удалось - явно укажи это

## Результат

1. **Изменения** - что реализовано и где
2. **Проверка** - что проверено и с каким результатом
3. **Проблемы** - что осталось нерешённым
4. **Релизы** - порядок развёртывания, если необходим
